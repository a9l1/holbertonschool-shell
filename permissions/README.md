# Shell Permissions

This project covers Linux users, groups, and file permissions.

## Scripts

- 0-iam_betty: Switches the current user to betty.
- 1-who_am_i: Prints the effective username of the current user.
- 2-groups: Prints all groups the current user belongs to.
- 4-empty: Creates an empty file named hello.
- 5-execute: Adds execute permission to the owner of hello.
- 6-multiple_permissions: Adds execute permission to owner and group, and read permission to others.
- 7-everybody: Adds execute permission to all users for the file hello.
- 8-James_Bond: Sets the permissions of hello to 007.
- 9-John_Doe: Sets the permissions of hello to 753.
- 10-mirror_permissions: Copies the permissions of olleh to hello.
- 11-directories_permissions: Adds execute permission to all immediate subdirectories without changing regular files.
