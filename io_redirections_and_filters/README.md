# Shell, I/O Redirections and Filters

- 0-hello_world: Prints "Hello, World" followed by a new line.
- 1-confused_smiley: Prints a confused smiley with special characters.
- 2-hellofile: Displays the entire content of /etc/passwd.
- 3-twofiles: Displays the contents of /etc/passwd and /etc/hosts.
- 4-lastlines: Displays the last 10 lines of /etc/passwd.
- 5-firstlines: Displays the first 10 lines of /etc/passwd.
- 7-file: Creates a file with a special-character name containing Best School.
- 8-cwd_state: Saves the detailed directory listing to ls_cwd_content, overwriting previous content.
- 9-duplicate_last_line: Duplicates the last line of the file iacta.
- 10-no_more_js: Deletes all regular .js files in the current directory and its subdirectories.
- 11-directories: Counts all directories and subdirectories, including hidden ones, excluding the current directory.
- 12-newest_files: Displays the 10 newest entries in the current directory, sorted from newest to oldest.
- 13-unique: Displays sorted words that appear exactly once in the input.
- 14-findthatword: Displays lines containing the pattern root from /etc/passwd.
- 16-whatsnext: Displays lines containing root and the three following lines from /etc/passwd.
